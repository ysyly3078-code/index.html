# 1000 English Nouns · إتقان الأسماء

تطبيق ويب بسيط لتعلم الأسماء الإنجليزية مع نطق أمريكي واضح.

## الميزات
- بطاقة واحدة لكل كلمة (سهلة التركيز)
- نطق أمريكي واضح (en-US) مع اختيار الصوت والسرعة
- تنقل بسيط: السابق / التالي / خلط عشوائي
- فلترة حسب القسم
- اختصارات لوحة المفاتيح: ← → للتنقل، مسافة للنطق

## الملفات
- `index.html` — التطبيق كامل
- `words.json` — بيانات الكلمات (100 كلمة في قسمين)

## النشر على GitHub Pages
1. ارفع الملفات الثلاثة إلى المستودع.
2. اذهب إلى **Settings → Pages**.
3. Source: **Deploy from a branch** → `main` → `/ (root)` → **Save**.
4. انتظر دقيقة، ثم افتح: `https://USERNAME.github.io/REPO-NAME/`
