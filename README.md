# 1000 English Nouns · إتقان الأسماء

تطبيق ويب تفاعلي لتعلم الأسماء الإنجليزية مع نطق أمريكي واضح.

## الميزات
- بطاقة واحدة لكل كلمة (سهلة التركيز).
- نطق أمريكي واضح (en-US) مع إمكانية اختيار الصوت والسرعة.
- تنقل بسيط: السابق / التالي / خلط عشوائي.
- فلترة حسب القسم.
- دعم اختصارات لوحة المفاتيح: ← → للتنقل، ومسافة للنطق.

## هيكل الملفات
تم تقسيم قاعدة البيانات إلى 4 ملفات لتسهيل التعديل وتجنب مشاكل المتصفح:
- `index.html`: كود التطبيق (الواجهة والبرمجة).
- `words_1.json`: الأقسام 1 إلى 5 (250 كلمة).
- `words_2.json`: الأقسام 6 إلى 10 (250 كلمة).
- `words_3.json`: الأقسام 11 إلى 15 (250 كلمة).
- `words_4.json`: الأقسام 16 إلى 20 (250 كلمة).

> التطبيق يقوم بقراءة الملفات الأربعة ودمجها تلقائياً.
